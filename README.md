## 九、CN2 线路到底是什么，为什么重要

买香港服务器经常会看到 CN2、CN2 GIA、CN2 GT 这些词，简单解释一下。

CN2 是中国电信的下一代承载网，相比传统 163 骨干网，拥堵更少、丢包率更低、晚高峰更稳定。CN2 又分两种：

- **CN2 GIA**（Global Internet Access）：全程走电信高速通道，速度最快，价格也最高。恒创香港机房走的就是这条线路。
- **CN2 GT**（Global Transit）：国际段走 CN2，国内段可能切换到 163 网络，价格便宜但高峰期偶尔会拥堵。

从实际测评看，恒创香港 CN2 GIA 线路电信用户双程走 59.43 开头的 CN2 节点，联通走 AS4837 优化线路，移动走 CMI 直连。三网访问延迟都能控制在 10-40ms 以内，晚高峰丢包率低。如果你的用户主要在国内，选 CN2 线路不会错。
